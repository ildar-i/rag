# Void Core

Void Core была массивной боевой станцией размером с небольшую луну, созданная Void Dominion как оружие массового уничтожения.

Создание
Void Core была спроектирована для полного уничтожения планет. Станция использовала огромный лазерный луч, способный испарить целую планету за один выстрел.

Технические характеристики
Void Core была размером примерно 160 километров в диаметре. Станция имела два основных компонента: северный и южный полюс, каждый из которых содержал суперлазер.

Уязвимость
Несмотря на свою мощь, Void Core имела критическую уязвимость - небольшое вентиляционное отверстие, которое вело прямо к реактору. Этой уязвимостью воспользовалась Resistance Front для уничтожения станции.

Первая битва
Первая Void Core была уничтожена во время Битвы при Pacifia, когда Keth Valdris использовал Synth Flux для точного выстрела в критическую точку.

Вторая Void Core
Вторая Void Core была еще более мощной и имела защиту от предыдущей атаки. Однако она также была уничтожена силами Resistance Front.
