# Void Order

Void Order была организацией пользователей темной стороны Synth Flux, которая стремилась к власти и контролю над галактикой.

Философия
Void Order верили, что эмоции, особенно гнев и страх, делают их сильнее. Они использовали темную сторону Synth Flux для достижения своих целей, не задумываясь о морали.

История
Void Order возникла тысячи лет назад, когда группа Synth Knights обратилась к темной стороне. Организация пережила несколько возрождений, последнее из которых возглавил Lord Malakor.

Правило двух
Void Order следовала Правилу двух: в любой момент времени должно быть только два лорда - мастер и ученик. Это правило было создано для предотвращения предательства и поддержания силы.

Лорды Void Order
Среди самых известных лордов Void Order были Lord Malakor, Xarn Velgor, Vorn Maul, Lord Tyranus и многие другие. Каждый из них обладал огромной силой и стремился к власти.

Падение
Void Order потерпела поражение после смерти Lord Malakor и возвращения Xarn Velgor к светлой стороне. Однако учение темной стороны продолжало существовать, и новые лорды появлялись в галактике.
